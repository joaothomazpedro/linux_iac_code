## Features

- Updates system packages.
- Installs Apache2 and Unzip.
- Downloads website files from GitHub.
- Extracts and deploys files to `/var/www/html/`.

## Requirements

- Ubuntu Linux
- Internet connection
- Root or sudo privileges

## Usage

```bash
git clone https://github.com/joaothomazpedro/linux_iac_code.git
cd linux_iac_code
chmod +x script_iac.sh
sudo ./script_iac.sh
```

Access the website at `http://localhost`.
